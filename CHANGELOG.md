# Changelog

## 1.1.0 — 2026-10-21

- добавлена загрузка и прикрепление файлов к текущей МКАБ;
- вид документа выбирается из активного справочника `atf_FileType`;
- файл получает UUID-имя с сохранением исходного расширения и сохраняется в `UploadRoot`;
- после успешной записи файла создаются `atf_FileInfo` и `atf_FileAttachment` в одной SQL-транзакции;
- если запись в БД не удалась, загруженный файл удаляется из файлового хранилища;
- добавлен аудит загрузок с MKABID, идентификаторами созданных записей, IP, форматом и размером;
- добавлено отдельное подключение `MisWriteDb` для минимально-привилегированной SQL-записи;
- добавлены настройки `UploadRoot`, `MaxUploadSizeMb`, `UploadCreateUserId`, `UploadCreateUserName`;
- добавлена диагностическая SQL-проверка соглашения об именовании файлов.

## 1.0.0 — 2026-10-20

- просмотр прикреплённых файлов пациента по MKABID;
- SQL + SMB backend без передачи UNC-пути в браузер;
- Zrimo + ShrimpDocViewer;
- PDF, Office, OpenDocument, изображения, TIFF, CSV/TSV, RTF/TXT;
- печать открытого документа;
- полноэкранный просмотр и скачивание оригинала;
- нормальное отображение дат без времени;
- колонка «Формат» без технического имени файла;
- изменяемая ширина списка документов;
- исправлена загрузка PDF runtime-assets Zrimo;
- исправлено закрытие окна печати Chromium при работе по сетевому адресу;
- конфигурация с секретами вынесена из Git в локальный `web.config`.
